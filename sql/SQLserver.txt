חלק 2: Where & Order by clauses
טבלת Olympic
1.1 - Present all the columns for athletes who are 18 years old
SELECT * FROM Olympic WHERE age = 18;

1.2 - Present all the columns for athletes whose weight is over 50 kg
SELECT * FROM Olympic WHERE weight > 50;

1.3 - Present all the columns for athletes who participated in the Summer Games, and order them by age
SELECT * FROM Olympic WHERE season = 'Summer' ORDER BY age;

1.4 - Present all the columns for female athletes from Mexico. Order them by the years column
SELECT * FROM Olympic WHERE sex = 'F' AND team = 'Mexico' ORDER BY year;

טבלת Pokemon
2.1 - Present the name and abilities of Pokemons that include "Solar Power" in their abilities
SELECT name, abilities FROM pokemon WHERE abilities LIKE '%Solar Power%';

2.2 - Present all the columns for Pokemons whose female_rate is over 0.2, and order them by Name in a descending order
SELECT * FROM pokemon WHERE female_rate > 0.2 ORDER BY name DESC;

2.3 - Present the name, primary color and speed columns for Pokemons whose primary color is green or red, and their Name starts with the letter "C". Order them by their speed
SELECT name, primary_color, speed FROM pokemon WHERE (primary_color = 'green' OR primary_color = 'red') AND name LIKE 'C%' ORDER BY speed;
